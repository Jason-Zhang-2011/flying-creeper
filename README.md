# What mod to make

make a mod that makes all the creepers fly in the world(like bees)

-Make textures for the wings of all creepers
-wings may drop(35% per creeper)
-player can use the wings to fly, like using elytra, but the wings can break easily for players(not for creepers, creepers can use them permanntely)

-When the flying creepers explodes, the damage is not as high on on the ground


# Rules when making the mod
The mod template is generated by Architecture, 1.21.11 fabric + neoforge

make sure to check OLD_AGENTS.md(mainly for Architecture generated templates), you may also check AGENTS.md --> rules for all mod making
